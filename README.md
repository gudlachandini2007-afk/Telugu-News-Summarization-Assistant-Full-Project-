# AI Headline & Subheadline Generator

## Overview

AI Headline & Subheadline Generator is a React-based newsroom assistant designed to help editors generate multiple Telugu headline and subheadline suggestions from a news article. The application reduces editorial effort while ensuring that the final publishing decision remains under editor control through an approval workflow.

## Features

* Paste Telugu or English news articles
* Generate multiple Telugu headline suggestions
* Generate multiple Telugu subheadline suggestions
* Character and word count tracking
* Editor headline selection
* Mandatory headline approval workflow
* Responsive and modern user interface

## Workflow

1. Paste a news article into the input area.
2. Click **Generate Headlines**.
3. Review the generated headline suggestions.
4. Select the preferred headline.
5. Approve the selected headline.
6. Review the generated subheadline suggestions.
